# 【解惑】快生了 要住院 我该怎么办

> 更新时间：2026-09-17 (UTC+8)

经过了十月怀胎，很多接近临产准妈妈们内心的紧张除了对即将来到世界上的宝宝，可能还会对即将进入医院的陌生环境感到紧张。

**今天，我们把临产住院后的流程跟大家讲解一下，帮您消除一些小紧张。**

**1. 正常工作时间（周一到周日上午 8 : 00—12 : 00 ，下午14 : 00—18 : 00）入院**

（1）先到产科门诊挂号、检查

如需办理入院，大夫会开好入院通知单，家属携带产妇的身份证、医保卡（省医保及市医保在住院处办理手续时均需将医保卡暂放在住院处）、银行卡/ 现金，到住院处办理入院。

****

（2）携带入院单、准生证复印件（省/市医保者）、生育备案表（省医保者）到一号病房西区的楼三楼或者四楼（入院单上会有具体病房楼层的安排）产科病房的护士站办理入院。

****

护士将会给您做基本生命体征（体温、脉搏、呼吸、血压）的测量，给您介绍科室情况，如：病区环境和规定、科主任、护士长等，陪您找到您的主管大夫。

（3）主管大夫会询问您的基本情况（产检、既往史、家族史等），查看您的检查报告单（近期的B超单、心电图、化验单，一周以内的血常规、血型等，根据您的具体情况安排相应检查），责任护士带领您回病房，再次自我介绍，介绍病房环境及科室相关规定，遵医嘱给予胎心监护，氧气吸入30分钟。

那如果是在非工作时间，比如中午的时候来住院，怎么办呢？

**2. 非工作时间（周一到周日中午12 : 00—14 : 00，夜间18 : 00—次日8 : 00）**

遇到如下情况

1）阴道溢液

突感有液体自阴道流出或无控制的“漏尿”，请立即平卧、入院；

2）阵发性或持续性腹痛；

3）阴道出血；

4）自觉胎动过多或过少；

5）其他不适症状如头晕，头痛，视力模糊，心慌，气短，胸闷或走路上楼心慌气短等。

请先到急诊科挂号，如需入院，大夫会开入院通知单给您，由医务人员陪同您至产科病区。

希望这些可以帮您消除内心的小紧张，河北省人民医院产科团队将以“高度责任感，至高的服务”随时欢迎您的到来，陪伴您共同迎接宝宝的到来！
