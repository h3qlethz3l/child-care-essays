# “三胎时代”来袭，备孕三胎要做好哪些准备？

> 更新时间：2026-09-17 (UTC+8)

伴随着“六一国际儿童节”的到来，5月31日中国新出台了：**《关于优化生育政策促进人口长期均衡发展的决定》**。新闻一出便引起了热议，微博热度更是持续沸腾。
来源：微博
顾名思义，新政策“三孩生育政策”就是国家表示将进一步优化生育政策，实施一对夫妻可以生育三个子女政策及配套支持措施，有利于改善国家人口结构、落实积极应对人口老龄化国家战略、保持国家人力资源禀赋优势。
其中，网友们所关心的**10个**三孩政策配套支持措施，囊括教育、休假、保险、税收、住房、女性就业等问题。
**国家都为大家排除了后顾之忧，但是是不是所有妈妈都适合”拼三胎呢？****想要准备“拼三胎”，要先做好哪些准备呢？**

**孕前检查需全面**
First Step
准备三胎的宝妈年龄普遍偏大，患有内分泌紊乱、肥胖等问题几率增加，因此要重视孕前检查。 

**01**

Point

**生殖系统检查**

主要是通过采集阴道分泌物来检查生殖系统的健康状况，是否存在滴虫、霉菌、支原体衣原体感染、阴道炎症，以及淋病、梅毒等性传播性疾病。  

**02**

Point

**尿常规检查**

怀胎十月对女性的肾脏是一个严重的考验，身体的代谢增加，会使肾脏的负担加重，如果负荷不了会导致流产发生。  

**03**

Point

**妇科内分泌**

主要是检查激素是否正常，包括卵泡促激素、黄体生存激素等6个项目。 

**04**

Point

**脱畸全套检查**

夫妻双方身体存在某些病毒可引起怀孕后引起胎儿畸形，脱畸全套检查内容包括风疹、弓形虫、巨细胞病毒三项。

**05**

Point

**染色体异常**

任何以防存在隐性染色体异常的，受精后的胚胎都会有遗传性疾病。 

**06**

Point

**肝功能检查**

肝功能检查目前有大小肝功能两种，大肝功能除了乙肝全套外，还包括血糖、胆质酸等项目。  

**07**

Point

**男方也要检查**

基本检查包括：精子浓度、精子活力、精子形态和精子顶体酶等。  
**温馨提醒：**孕前检查是需要男女双方共同参与，检查时间选择在怀孕前3-6个月，女性检查要避开月经期。

**饮食、生活习惯需要调整**
Second Step
孕妇膳食指南在一般人群的人群膳食指南的基础上补充了如下5条内容（划重点）：  

**01**

Point

**补充叶酸**

整个孕期应口服叶酸补充剂400微克/天，每天摄入绿叶蔬菜。常吃含铁丰富食物，孕中晚期应每天增加20-50g红肉，每周吃1-2次动物内脏或血液。孕妇除坚持选用加碘盐外，还应吃含碘丰富的海产食物，如海带、紫菜等。  

**02**

Point

**碳水化合物**

孕吐严重者，可少量多餐进食，保证摄入足量含必要量（至少130克）碳水化合物的食物。  

**03**

Point

**奶、鱼、蛋、禽、瘦肉**

孕中晚期适量增加奶、鱼、蛋、禽、瘦肉的摄入。孕中期开始，每天增加奶200克，使奶的总摄入量达到500克/天。孕中期每天增加鱼禽蛋瘦肉共计50克，孕晚期再增加75克左右。每周最好食用深海鱼2-3次。

**04**

Point

**适量身体活动**
  维持孕期适宜增重，减少孕期合并症及并发症。孕中晚期应每天进行30min左右的中等强度的身体活动。控制心率在95-133次/min适宜。  

**心理准备需做好**
Third Step
准备生三胎的夫妇要做好身体和心理双重准备，才能愉快的迎接一个新生命的降临，需要多和家庭成员进行心理沟通。  高龄夫妇备孕半年以上仍没有怀孕，应及时寻求医师的帮助，进行孕前评估以及辅助生育的治疗。
