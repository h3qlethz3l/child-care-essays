# 云龙宝宝有用科普·你问我答 | 乳腺检查 那些你应该知道的事儿

> 更新时间：2026-09-16 (UTC+8)

乳腺健康对于女性来说至关重要，可怎么能够做到科学监测，及时发现、及时治疗呢？

最常见的乳腺检查方法就是乳腺超声，作为一种无创、无辐射的影像学检查方法，乳腺超声已经成为现代女性健康管理中不可或缺的一部分。对乳腺癌的“早发现、早诊断、早治疗”发挥着至关重要的作用。

咱们今天就来唠唠，关于乳腺超声，你不知道的那些事儿！

**Q**

**患者有疑问：**

现在检查手段太多了，我们乱不清！

比如乳腺超声与钼靶、X 线及 MRI检查到底有什么区别，都是看乳腺，检查一个不行吗？

**A**

**昆妇幼超声医学科魏芳主任医师答：**

钼靶 X 线能准确显示钙化和毛刺，尤其微小钙化显示率优于超声，但备孕妇女不宜检查，并且该检查方式，对乳房边缘的肿瘤易漏诊。

MRI 对于软组织病变分辨率较高，但由于检查费用昂贵，所以一般情况下不建议重复用这一方式进行检查。

乳腺超声检查无辐射，无损害，并且检查费用相比之下亲民，适合普查及可疑病变的动态随访，可以观察肿块的血流情况，对腋窝淋巴结的显示优于钼靶 X 线……

**Q**

**患者有疑问：**

那当身体出现哪些情况时，应该使用乳腺超声呢？

**A**

**昆妇幼超声医学科魏芳主任医师答：**

乳腺超声一般会在八类情况下使用：

1. 找出乳房症状的原因，如疼痛、肿胀和发红。

2. 检查乳房自检或体格检查发现的乳房肿块。

3. 检查乳房 X 光检查或磁共振成像（MRI）的异常结果。

4. 检查年轻女性的乳房，因为年轻女性的乳房组织往往更致密，而乳房 X 光检查可能显示不了那么多细节。

5. 指导放置针或其他导管排出液体（囊肿）或脓液（脓肿），取乳腺组织样本（活检），或指导乳腺手术。

6. 观察囊肿或非癌性肿块（纤维腺瘤）的大小变化。

7. 查看癌症在乳房中的扩散程度。

8.检查有硅胶乳房植入物或致密的乳房。在这种情况下，乳房 X 光检查可能看不到乳房肿块。

**Q**

**患者有疑问：**

做乳腺B超有什么需要注意的吗？

**A**

**昆妇幼超声医学科魏芳主任医师答：**

做乳腺B超要注意四件事

1. 进行乳腺比超检查最好穿可以容易脱掉的上衣。

2. 如怀疑乳腺增生，最好在月经干净后 1 周进行检查。

3. 对有乳头溢液患者，检查前应避免挤压导管，充盈的导管可利于查出溢液原因。

4.检查前应避免乳腺导管造影和穿刺活检，以免造影剂和出血影响诊断结果。
